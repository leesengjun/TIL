# 15강

## 오늘 배운것

`ElevatedButton` 디자인 특징: 배경색이 채워져 있고 
그림자 효과가 있어서 화면에서 살짝 떠 있는 듯한 입체감을 줍니다.
화면에서 가장 중요한 핵심 액션(예: 저장, 제출)에 주로 쓰입니다

``TextButton`` 테두리도 없고 배경색도 없는 평평한 형태입니다. 텍스트 자체에 링크가 걸린 것처럼 보이며,
  중요도가 낮거나 보조적인 액션(예: 취소, 더 보기, 비밀번호 찾기)에 주로 쓰입니다

``outlinedButton``배경은 투명하지만 버튼의 형태를 보여주는 외곽 테두리 선이 있습니다. ElevatedButton 보다는 강조를 낮추고 싶고,
  TextButton 보다는 명확하게 버튼임을 보여주고 싶을 때(중간 수준의 중요도) 사용합니다
