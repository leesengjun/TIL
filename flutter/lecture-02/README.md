## 오늘 배운 내용

- `Container`는 크기, 색상, 정렬 등을 설정할 수 있는 박스 위젯이다.
- `Column`은 위젯들을 세로 방향으로 배치한다.
- `Row`는 위젯들을 가로 방향으로 배치한다.
- `mainAxisAlignment`는 주축 방향 정렬을 설정한다.
  - Column에서는 세로 방향
  - Row에서는 가로 방향
- `MediaQuery.of(context).size.width`를 사용하면 현재 화면의 너비를 가져올 수 있다.
- 화면 너비를 2로 나누면 화면의 절반 크기만큼 위젯을 만들 수 있다.
